Set up ToolGraft.

Your agent, connected to the websites you use. This local developer preview needs Chrome 138+, Node 24+ and an agent on the same computer. No ToolGraft account or model key.

Installation walkthrough · Set up manually · Troubleshooting

Install the extension yourself

Download the local Chrome preview and unzip it. Open chrome://extensions, enable Developer mode, choose Load unpacked and select the unzipped folder. In ToolGraft’s Details, enable Allow User Scripts.

This is an unpacked local preview. A public release and Chrome Web Store listing are not available yet.

Once connected, tell your agent which website to use and what you want to do. You approve site access, adapter installations and writes in the extension.
