Set up ToolGraft.

Your agent, connected to the websites you use. This local developer preview needs Chrome 138+, Node 24+ and an agent on the same computer. No ToolGraft account or model key.

Install the extension

Download ToolGraft for Chrome

  1. Unzip the download.
  2. Open chrome://extensions, turn on Developer mode, choose Load unpacked and select the unzipped folder.
  3. In ToolGraft’s Details, turn on Allow User Scripts. Pin ToolGraft from Chrome’s extensions menu.

A Chrome Web Store listing is on the way. Until then, this preview installs unpacked and updates manually.
