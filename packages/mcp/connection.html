ToolGraft

Connect your agent.

Open ToolGraft in your browser’s extensions menu, then choose Connect this agent.

With one-tab connections enabled in ToolGraft, this page opens the extension’s approval screen automatically. You still choose Connect this agent.

Your approval connects this browser to the agent running on your computer. There’s no account or API key to enter.

Can’t find ToolGraft?

Use the extensions menu next to the address bar. If ToolGraft isn’t there, load the extension first, then return to this tab. Open this link in the browser where you installed it.

Link expired or connection failed?

Ask your agent for a fresh ToolGraft connection link. Keep the agent running while you connect. If you use a remote or browser-only agent, this local connection won’t reach it.

This private link expires after five minutes and works once. Don’t share it. Opening it alone grants no access.
